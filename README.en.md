# Romain Moussac — the praxora portfolio

_[Version française](README.md)_

Full-stack developer and UX/UI designer for 25 years, I am building **praxora**, a small digital
tools company based in Aveyron, France. This repository is my **portfolio**: it shows how I
design, what I choose and why, and what my code looks like, drawn from real projects.

The projects themselves are private; what you read here was written to be read, and reviewed so
that nothing sensitive is exposed. Pages are written in French; each one starts with a short
English summary.

## In two minutes

- **What I do**: complete web applications, from interface design to production — TypeScript,
  React / Next.js, Node.js, PostgreSQL, Docker.
- **What I am building now**: [praxoraXwebbuilder](projets/praxora-webbuilder/), a platform that
  builds and manages showcase websites for freelancers and small businesses, with a full export
  so that each client stays the owner of their site.
- **How I work**: written, reasoned decisions, a ticket for everything, automated tests, and an
  AI (Claude) used as an architect colleague within explicit rules — see
  [Working with AI](methode/travailler-avec-l-ia.md) (in French).
- **Online**: [nine demo websites](projets/praxora-webbuilder/demos.md) built with the platform,
  and [www.praxora.fr](https://www.praxora.fr).
