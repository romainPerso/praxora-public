# Exemples de code

> **In English** — Commented excerpts from the private repository, chosen to show how the
> platform is built: a block declared once from which everything else is derived, and a block that
> evolves without breaking published sites. Excerpts are simplified; nothing security-related is
> shown as-is.

est indiquée sur chaque page. Les commentaires du code sont d'origine : le projet est écrit en
français, noms de variables compris.
